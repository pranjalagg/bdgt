# Native-feeling UI (overnight redesign) Plan

> Work on branch `claude/native-ui` (made from `claude/intelligent-davinci-7qblqz` at `ced24f0`). Steps use checkbox (`- [ ]`) syntax for tracking; a resumed session continues at the first unchecked step.

**Goal:** The app feels like a native Android/iOS app on a phone, inspired by the owner's sample video (a dark fintech concept: safe-to-spend ring, bright tiles, chip filters, transactions grouped by day in rounded cards, four-tab bottom bar). Nothing that works today may break; desktop keeps working.

## Rules

- UI only. A logic change is allowed only where a screen needs it, with a test.
- After every change: the smoke check (`node <scratchpad>/ui/check.cjs <dir> smoke`, dev server `VITE_SUPABASE_URL= npx vite dev --port 5174`), `npx vitest run` and `npm run check`. Screenshots (`shots`) after each visual step.
- Small commits (`git commit --no-gpg-sign`, no attribution lines), pushed to `claude/native-ui` only. Never touch `claude/intelligent-davinci-7qblqz`, never publish the `android-latest` release, never run the Pages deploy.
- Keep the app's colour meanings: green is money set aside, red is overspent, buckets carry their own colours, controls stay ink (neutral). New: periwinkle for upcoming bills.
- Motion only under `prefers-reduced-motion: no-preference` (opacity fallback); press scale `0.96` over `150ms ease-out`, never on disabled controls; hover styles only on hover-capable pointers.

## Direction

- **Surfaces:** dark mode near-black (`#0e0f11` page, `#18191c` cards, `#222327` raised), light mode warm white; cards `20px` radius, sheets and tiles `28px`; depth from a 1px ring, not borders.
- **Type:** Archivo (width 125%) for large titles and hero figures; IBM Plex Sans for text; amounts in Plex Sans with tabular figures (mono reads as a terminal, not a native app).
- **Shell:** edge-to-edge under the status bar (`viewport-fit=cover` + safe-area insets), Material-style bottom bar with a pill behind the active icon, extended "Log" button, large page titles.
- **Dialogs:** bottom sheets on phones (handle, swipe down to close, contained scroll), centred dialogs on desktop.
- **Dashboard:** safe-to-spend ring; "Upcoming bills" and savings tiles; the rest regrouped into rounded cards.
- **Activity:** bucket chips instead of a dropdown; days as headed cards; tapping a row opens its edit sheet (delete lives there).
